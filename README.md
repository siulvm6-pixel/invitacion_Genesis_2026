# Invitación de Génesis — 2 años

Primera versión de la invitación web estática, lista para personalizar y publicar con GitHub Pages.

## Datos incluidos
- Cumpleaños: sábado 21 de noviembre de 2026, 1:30 p. m.
- Lugar: Salón Cabaña Don Javi
- Temática: aventura infantil colorida, Skye y Everest
- Foto de Génesis: espacio reservado
- Música: botón para activar/silenciar
- Cuenta regresiva y confirmación por WhatsApp
- Ubicación: enlace de Google Maps proporcionado para el evento

## Personalizar la fotografía
Copia la foto elegida a `assets/genesis.jpg`. El espacio reservado se mostrará automáticamente cuando el archivo exista.

## Añadir música
Copia un archivo de audio con permiso de uso a `assets/musica.mp3`. La música no se reproduce automáticamente; la persona invitada debe pulsar el botón.

## Ajustes recomendados antes de publicar
1. Confirmar que el enlace de Maps apunta a la entrada correcta del salón.
2. Si se quiere que las confirmaciones lleguen directamente al organizador, editar `script.js` y cambiar `https://wa.me/?text=` por `https://wa.me/NUMERO?text=` usando el número en formato internacional sin `+`, espacios ni guiones.
3. Probar en celular y computadora.
4. No incluir fotos de menores sin valorar quién podrá ver el sitio. GitHub Pages publica la página en Internet.

## Publicar con GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets`.
3. En Settings → Pages, selecciona la rama principal y la carpeta raíz.
4. Guarda y espera a que GitHub muestre la URL publicada.

## Nota
La página usa tipografías de Google Fonts cuando hay conexión. Los personajes oficiales y música de Paw Patrol no se incluyen como archivos; agrega únicamente materiales que tengas autorización para utilizar. Los emojis de cachorros son marcadores provisionales para la primera versión.
